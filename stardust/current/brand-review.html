Tensions

T-lcp-no-eager
The first <img> in the DOM has about:error as its src (a broken image reference), which means the actual first visible image (media_1300083772e9…, alt="Speed and momentum on the pitch") is lazy-loaded. This likely delays LCP on the live page. Fix: ensure the hero image has loading="eager" and fetchpriority="high".
T-h1-level-regression
The first heading in the DOM is an H2 ("Default header promo") inside the header/nav, before the H1 ("Brazil Goes for the Championship") in <main>. Screen readers and crawlers will encounter an H2 before any H1 — a heading hierarchy violation. Fix: remove or demote the header H2, or change it to a <p> or aria-label.
T-demo-content-overlay
The live main branch is serving Brazil World Cup editorial content ("Brazil Goes for the Championship") while the product being showcased is Author Kit. The CTAs link to GitHub (author-kit repo) and aem.live, confirming this is intentional demo content — but the product identity ("Author Kit") surfaces only in the header logo and the last few sections. The first 60% of the page reads as a football editorial, not a developer tool landing page. Note for direction: the redesign should clarify which content is demo/illustrative and which is canonical product messaging.
T-single-font-family
The entire site uses a single typeface (Montserrat) for both headings and body. While Montserrat is variable (wght 100–900), the lack of a complementary type pairing means all typographic hierarchy is achieved through weight and size alone. This is a deliberate simplicity choice but limits expressive range.
T-dark-mode-supported ✓
Dark mode is fully implemented via CSS light-dark() and .dark-scheme section classes. Both light and dark surfaces are consistently handled.
T-type-scale-modular ✓
Heading scale is modular (~1.122 ratio): 32.44 → 28.83 → 25.63 → 22.78 → 20.25 → 18px. Consistent and well-structured.
